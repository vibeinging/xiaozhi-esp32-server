# 家长每日儿童聊天安全复查设计

## 目标

管理后台每天复查孩子与设备的文字聊天，识别需要家长关注的风险，并把结果送到设备所属家长账号的“安全中心”。

默认策略：

- 每天 22:00（`Asia/Shanghai`）生成一次日报；
- 只保存文字，不保存原始语音；
- 聊天文字保留 7 天，安全日报和已脱敏风险事件保留 90 天；
- 日报不展示完整聊天原文，不保存电话号码、验证码、密钥等敏感内容；
- `self_harm`、`immediate_danger`、`abuse_or_bullying` 等本地高确定性事件立即进入家长安全中心，不等待日报；
- 第一版使用后台站内提醒。短信、微信或邮件要等家长提供真实通知通道后再启用。

## 数据边界

开启安全复查时，系统改为：

- `mem_model_id=Memory_mem_report_only`；
- `chat_history_conf=1`；
- 不创建长期对话记忆；
- 不上传、保存或发送原始音频。

关闭功能时恢复开启前的记忆模型和聊天记录配置。

## 处理流程

1. 设备完成 ASR 后，在上传前先运行本地儿童安全规则。
2. 命中隐私或高风险规则时，只上报 `[儿童安全事件：分类，原文未保留]`，原话不进入后台。
3. 普通聊天按文字上报，后台在调用大模型前再次隐藏手机号、邮箱、网址、验证码和密钥。
4. 定时任务调用智能体自己的小模型或主模型，要求只返回固定 JSON。
5. 服务端校验风险等级、分类、数量和长度后保存日报；模型输出中不接受聊天原文摘录。
6. 家长只能查看自己智能体的日报、紧急事件和设置。

## 风险等级

- `CRITICAL`：自伤、自杀、正在发生的危险；
- `HIGH`：疑似侵害、暴力、严重欺凌；
- `MEDIUM`：危险行为、用药、成人内容、强依赖；
- `LOW`：隐私泄露、需要家长操作、一般情绪或同伴冲突；
- `NONE`：没有发现需要家长处理的风险；
- `UNKNOWN`：模型调用或结果校验失败，需要家长人工查看。

## 失败与降级

- 大模型不可用时，不把结果写成“无风险”，而是生成 `UNKNOWN` 报告并计入未读提醒；
- 大模型声称存在风险却没有提供合规风险项时，也按复查失败处理；
- 本地已识别的高风险事件始终保留分类，即使大模型失败；
- 当天消息超过上限时，优先复查最新的 200 条和最新的 2.4 万字；
- 同一智能体同一天只保留一份日报，重复任务不会重复发送；
- 定时任务失败后至少间隔 30 分钟再重试；
- 清理任务只删除超过保留期的数据，不删除尚未生成日报的当天数据。

## 通知说明

当前第一版实现登录后台后的站内送达和未读状态。以后可接入家长微信、短信模板、邮件或 webhook；外部消息只发送“有风险报告，请登录查看”，不发送孩子原话。
