# 家长每日儿童聊天安全复查上线报告

## 结果

功能已直接部署到 `yiyiai.mediaprogram.cn`，当前版本目录为 `/opt/yingxiai/releases/v0.9.6-yiyiai-parent-safety-v9`。

- 已为绑定智能体开启每日复查；
- 每天 `22:00` 按 `Asia/Shanghai` 时区执行；
- 聊天文字保留 7 天，安全报告和风险事件保留 90 天；
- 当前提醒送到设备所属家长账号的“家长安全”页面；
- 复查失败会显示 `UNKNOWN` 并计入未读提醒，不会误报为“无风险”；
- 没有启用 `TextModerationPlus`。

## 隐私处理

- 不保存原始音频；
- 高风险或隐私原话在设备服务上报前替换成风险分类；
- 普通文字发给复查模型前，再隐藏手机号、邮箱、网址、验证码、密钥、地址和学校信息；
- 报告只保留分类、等级、时间段、原因和家长建议，不保存孩子原话；
- 普通聊天文字只用于 7 天内的安全复查，不进入长期记忆。
